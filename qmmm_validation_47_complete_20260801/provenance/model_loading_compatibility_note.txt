Model loading compatibility note
================================

The old RandomForestRegressor was serialized using scikit-learn 1.7.1.

The corrected 47-ligand analysis was run in the existing thesis_features
environment with:

- scikit-learn 1.9.0
- numpy 2.4.6
- scipy 1.17.1
- joblib 1.5.3

The model loaded successfully with joblib.load().

A scikit-learn InconsistentVersionWarning was emitted because the model was
created with version 1.7.1 and loaded with version 1.9.0.

The loaded model had:
- 4086 input features
- 100 estimators
- RandomForestRegressor class

The supplied feature list also contained 4086 unique feature names, matching
model.n_features_in_ exactly.

This version mismatch is recorded as a reproducibility limitation. The model
file and feature-list file were not modified or retrained.
