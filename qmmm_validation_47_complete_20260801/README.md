# Validation of the Old Random Forest Model Using 47 Complete QM/MM Structures

## 1. Aim

This analysis tests whether the previously trained random forest (RF) model
can predict the improved QM/MM barriers using the complete structures
generated by the new structural pipeline.

The main purpose of this rerun was to determine whether the weak correlation
found in the earlier 43-ligand validation was caused by the way the complexes
had been reconstructed.

## 2. Updated dataset

The updated validation dataset contains 47 ligands.

The supervisor provided one complete PDB structure for each ligand in:

`qmmm_validation/complete_structures/<ligand_id>.pdb`

Each complete PDB contains:

- the full protein complex
- GTP
- Mg
- the docked ligand with residue name `LIG`

The four ligands that had previously been excluded were successfully
recomputed and included in the updated `barriers.csv`:

- PV-000233762503
- PV-000233762504
- PV-000235112478
- PV-000239559019

The dataset checks confirmed:

- 47 barrier records
- 47 complete PDB structures
- exact agreement between barrier IDs and structure IDs
- protein, GTP, Mg, and LIG present in all structures

## 3. Difference from the earlier 43-ligand analysis

In the earlier analysis, the protein and ligand structures had to be combined
manually. This involved protein alignment, GTP transfer, ligand insertion,
and static complex reconstruction.

In the corrected analysis, the supplied complete structures were used
directly.

Therefore, the corrected workflow did not perform:

- protein alignment
- GTP transfer
- ligand insertion
- complex reconstruction

This removes the possibility that the earlier weak correlation was caused by
the reconstruction procedure.

## 4. Old RF model

The old model is a `RandomForestRegressor` containing 100 trees.

The model requires 4,086 distance features.

The model file and the stored feature list were checked against other
available copies using SHA256 hashes. The copies were identical.

The model had originally been saved using scikit-learn 1.7.1 and was loaded
in the current environment using scikit-learn 1.9.0. This produced an
`InconsistentVersionWarning`, but the model loaded successfully with:

- 100 trees
- 4,086 expected input features
- successful prediction for all 47 ligands

The version difference is recorded as a reproducibility limitation.

## 5. Feature generation

The original distance-feature code was applied directly to each complete PDB:

`compute_pp_dists_from_pdb(..., ligands=("GTP", "LIG"))`

Results:

- 47/47 structures processed successfully
- 4,086/4,086 required features recovered for every ligand
- no missing required features
- no duplicate feature names
- no NaN values
- no infinite values
- feature order exactly matched the stored RF feature list

The final feature matrix contained 47 rows and 4,086 model input features.

## 6. Prediction results

The improved QM/MM reference barriers had:

- mean: 27.0649 kcal/mol
- standard deviation: 1.6499 kcal/mol
- minimum: 23.2500 kcal/mol
- maximum: 30.6300 kcal/mol
- range: 7.3800 kcal/mol

The old RF predictions had:

- mean: 27.0637 kcal/mol
- standard deviation: 0.5234 kcal/mol
- minimum: 25.7644 kcal/mol
- maximum: 27.5074 kcal/mol
- range: 1.7430 kcal/mol

The prediction distribution was strongly compressed:

- prediction/reference SD ratio: 0.317
- prediction/reference range ratio: 0.236

Although the two means were almost identical, the RF predictions covered only
a small part of the variation observed in the QM/MM barriers.

## 7. Correlation and prediction error

For the 47 complete structures:

- Pearson r: 0.139
- Pearson p-value: 0.352
- Pearson bootstrap 95% CI: [-0.110, 0.382]

- Spearman rho: 0.133
- Spearman p-value: 0.372
- Spearman bootstrap 95% CI: [-0.162, 0.394]

- Kendall tau: 0.085
- Kendall p-value: 0.399

- regression slope: 0.044
- regression R-squared: 0.019

Prediction errors:

- MAE: 1.301 kcal/mol
- RMSE: 1.642 kcal/mol
- maximum absolute residual: 3.916 kcal/mol

The correlations were weak and not statistically significant. Both bootstrap
confidence intervals included zero.

The regression slope was close to zero, meaning that the RF prediction changed
very little even when the QM/MM barrier changed substantially.

## 8. Prediction compression

The old RF predictions were concentrated close to the dataset mean.

Low QM/MM barriers were generally overpredicted, while high QM/MM barriers
were generally underpredicted.

This behaviour is visible in the residual plot and is consistent with strong
regression toward the mean.

The nearly zero mean offset does not mean that the model predicted individual
ligands accurately. It only means that the average RF prediction was close to
the average QM/MM barrier.

## 9. Feature-importance analysis

The RF importance was distributed as follows:

- protein–protein features: 98.696%
- protein–GTP features: 1.026%
- protein–LIG features: 0.278%

Therefore, the model relied almost entirely on internal protein distances and
assigned very little importance to ligand-related features.

Across the 47 complete structures:

- 3,857 of 4,086 features had exactly zero variance
- these zero-variance features carried 91.290% of the total RF importance
- features with SD below 0.01 Å carried 91.364% of the total RF importance

The most important feature was:

`PRO1281-PRO1391`

For this feature:

- RF importance: 25.390%
- standard deviation across 47 structures: 0.000 Å
- distance range: 0.000 Å
- number of unique values: 1

Therefore, approximately one quarter of the entire model importance was placed
on one feature that was identical for all 47 ligands.

Among the 20 most important RF features, only `PRO62-PRO1279` showed substantial
variation, with an SD of approximately 0.509 Å. The other 19 had SD values of
0.000 Å at the reported precision.

## 10. Scientific interpretation

The old RF model did not transfer successfully to structures generated by the
improved pipeline.

This was not because the model file could not be loaded, and it was not because
the complete structures were incorrect.

The main problem was that the model relied on structural quantities that did
not vary in the new dataset.

Specifically:

- 98.7% of model importance came from protein–protein distances
- 91.3% of total model importance was assigned to features that were constant
  across the 47 structures
- ligand-related features contributed only 0.28% of total importance

As a result, the model had very little useful changing information from which
to distinguish one ligand from another.

The model therefore produced predictions close to the average barrier rather
than reproducing the ligand-specific QM/MM barrier variation.

## 11. Main conclusion

The corrected rerun confirmed that the weak correlation and compressed
predictions found previously were not artefacts of protein alignment, GTP
transfer, ligand insertion, or complex reconstruction.

The old RF model does not transfer to the improved structural pipeline because
its dominant input features remain fixed across the new structures.

The appropriate next step is to retrain a new model using barriers and
structural features generated consistently by the improved pipeline.

A future model should focus more strongly on quantities that actually vary
between ligands, such as:

- flexible-sidechain geometry
- protein–ligand contacts
- ligand position and orientation
- reaction-centre geometry
- other chemically relevant local descriptors



## 12. Final thesis figure regeneration

A final figure-formatting pass was performed for the dissertation after the
scientific analysis had been completed.

The purpose of this step was only to improve figure readability in the final
thesis PDF. The underlying data, sample selection, statistical calculations,
RF predictions, feature importances, and scientific conclusions were not
changed.

A separate plotting script was created:

`scripts/09_make_final_figures_final.py`

This script is based on the original:

`scripts/09_make_final_figures.py`

The final plotting script reads the existing analysis outputs directly:

* `predictions/old_rf_vs_qmmm_47_complete.csv`
* `results/tables/feature_importance_variance_all.tsv`
* `results/tables/rf_importance_by_feature_type.tsv`

It does not rerun:

* structure processing
* feature generation
* RF prediction
* bootstrap analysis
* feature-importance calculation
* model fitting or retraining

The plotting changes were limited to presentation. These included:

* increasing figure dimensions
* increasing title and axis-label font sizes
* increasing tick-label, legend, and annotation font sizes
* improving spacing and layout
* using thesis-consistent terminology in displayed figure text
* preserving the same plotted values and statistical relationships

The approximate font-size settings used for the final Matplotlib figures were:

* titles: 18 pt
* axis labels: 18 pt
* tick labels: 16 pt
* legends: 16 pt
* annotations: 16 pt

For figures containing many long feature labels, a slightly smaller y-axis
tick-label size was used to avoid overlap while maintaining readability.

The final plotting script also changed some display wording for consistency
with the dissertation. For example:

* `protein-LIG` was displayed as `protein–ligand`
* `protein-GTP` was displayed as `protein–GTP`
* `protein-protein` was displayed as `protein–protein`
* `Old RF prediction` was presented as `Existing RF prediction` where appropriate
* improved QM/MM barriers were described as improved-QM/MM activation barriers

These were display-only changes. The underlying feature-type classifications,
stored tables, predictions, and numerical results were not modified.

To ensure that the original figures remained available, the final plotting
script writes new files with the suffix `_final`. The original figure files
are therefore not overwritten.

The final figure files are:

* `results/figures/old_rf_vs_qmmm_47_complete_scatter_final.png`
* `results/figures/old_rf_vs_qmmm_47_complete_residuals_final.png`
* `results/figures/reference_vs_prediction_distribution_final.png`
* `results/figures/top_20_rf_feature_importance_final.png`
* `results/figures/top_20_rf_feature_variability_final.png`
* `results/figures/rf_importance_by_feature_type_final.png`

Equivalent PDF versions are also generated.

The final plotting script can be run independently using:


python scripts/09_make_final_figures_final.py


Only the existing result files listed above are required. Scripts `01`–`08`
do not need to be rerun for this figure-formatting step.

For the dissertation layout, multi-panel figures were also changed from
side-by-side arrangements to predominantly vertical arrangements where
necessary. This was a LaTeX presentation change only and did not modify the
figure contents or analysis. Existing LaTeX figure labels were retained so
that cross-references in the dissertation remained unchanged.
